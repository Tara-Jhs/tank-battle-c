# Tank Battle Game

A two-player terminal-based tank battle game developed individually in C as a university programming project.

## Features

- Two-player turn-based gameplay
- Terminal-based game interface
- Random initial positioning of tanks
- Tank movement with boundary checking
- Angle and shot-power input
- Projectile-motion simulation
- Collision detection with tanks, rocks, terrain, and game boundaries
- Player health management
- Input validation and error handling
- New-game and quit options

## Programming Concepts

- C programming
- Modular programming
- Functions and header files
- Structures
- One-dimensional and two-dimensional arrays
- Mathematical calculations
- Random-number generation
- Collision detection
- Input validation

## Project Files

- `game.c` — main program and game loop
- `game.h` — structures and function declarations
- `gamefunction.c` — implementation of game functions

## Development Environment

- Language: C
- Editor: Visual Studio Code
- Platform: Windows
